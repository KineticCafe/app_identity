# AppIdentity Security Policy

## LLM-Generated Security Report Policy

Absolutely no security reports will be accepted that have been generated by LLM
agents.

## Supported Versions

Security reports are accepted for the most recent major release with support for
the previous major version ending immediately. This applies both to the
specification and to the reference implementations.

> [!note]
>
> Security reports for the version 1 algorithm will not be accepted. It has a
> well-known token lifetime issue and exists solely to provide support to
> already existing apps until they can be upgraded.
>
> A future version of the specification will shift from _recommending_ against
> the use of version 1 to _prohibiting_ the use of version 1.

### Reference Release Support

If there is a flaw in the specification, security releases will be made to the
most recent major release of each reference implementation that supports the
active specification version.

### Language Runtime Support

- Elixir support is provided for the three most recent versions of Elixir and
  supported [Erlang/OTP versions][otp-versions]. As of December 2025, the
  support list is:

  | Elixir | Erlang         |
  | ------ | -------------- |
  | 1.16   | 24, 25, 26     |
  | 1.17   | 25, 26, 27     |
  | 1.18   | 25, 26, 27, 28 |
  | 1.19   | 26, 27, 28     |

  The oldest supported version of Elixir will not be deprecated until six months
  after the release of a new version of Elixir.

- JavaScript support is provided for the current and previous Node LTS versions
  (Node 22 and Node 24 as of December 2025), or the most recent Bun version.
  Other runtimes, including browser use, are supported at the discretion of the
  developers.

- Ruby support is for active versions of Ruby (MRI). As of December 2025, this
  is Ruby 3.2, Ruby 3.3, Ruby 3.4, and Ruby 4.0. Support for other Ruby runtimes
  depends on compatibility with the lowest version of Ruby supported.

## Reporting a Vulnerability

Create a [private vulnerability report][advisory] with GitHub.
